Privacy

Your watchlist

The symbols you add are stored in your own browser (local storage), not on the server. To fetch prices, the page sends each symbol to the server every few seconds.

Server logs

Like any website, the server keeps request logs (page, time, browser) for troubleshooting. The site is hosted on Microsoft Azure.
